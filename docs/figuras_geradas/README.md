# Figuras da monografia

Os diagramas atuais são os seis blocos Mermaid de `../TCC2_Grupo_19_Monografia.md`, sincronizados com os arquivos `.mmd` em `fontes/`. O GitHub renderiza esses blocos diretamente. A exportação para outro editor deve partir dessas fontes corrigidas.

## PNGs anteriores — não usar na versão final

- `figura_4_1_arquitetura.png` a `figura_4_6_sequencia_webhook.png`: exportações anteriores à correção dos diagramas. Foram preservadas para consulta; não estão vinculadas na monografia atual e não foram regeneradas.
- `figura_4_7_catalogo.png` a `figura_4_12_pedidos.png`: protótipos de interface, não capturas da implementação. Não substituir os placeholders por esses arquivos.

## Capturas a produzir

A seção 4.5 da monografia contém sete placeholders, com as rotas e as instruções de captura em comentários Markdown. Capturar o sistema em execução com dados de teste e substituir cada marcador no local indicado. O guia de pendências contém o checklist correspondente.

As capturas devem mostrar catálogo, ficha da obra, pedido com reserva, avisos do wizard, portfólio, detalhe administrativo do pedido e relatório de vendas. As fontes das figuras são propostas para as futuras capturas, não declarações de que elas já foram produzidas.
